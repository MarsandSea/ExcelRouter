# ExcelRouter · 表格拆分、合并汇总 & 文件加密分发

## 一句话

一张几千行的总表，按部门 / 区域 / 工号 / 姓名拆成几十个文件发给不同的人——
跟 AI 说一句「把这张工资表按人拆成一人一份」就拆好了，**原表格式原样保留**。

手工做这件事是「筛选 → 复制 → 新建工作簿 → 粘贴 → 调格式 → 另存」重复几十遍，
一个下午；写脚本则要自己处理表头识别、样式复制、跨文件合并。这个技能把这两件事都省了。

反过来也一样：各单位交回来几十个表，说一句「把这个文件夹里的表合成一张」就合好——
按列名对齐、表头格式原样、每行标明来自谁；表是发下去让大家填的，还能先查出谁没交、谁漏填了哪几行，
通报写好了直接复制发群。

## 三步，说人话就行

```
① 看看表          ② 说怎么拆           ③ 拿走文件
   有哪些字段   →    按部门 / 按人    →    AI 把输出路径和份数报给你
   有哪些取值        只拆哪几个值
```

直接说给 AI 听：

- 「把这张工资表按人拆成一人一份」
- 「这个文件夹里所有网点表按网格拆一遍，同一个人的合并成一份」
- 「按部门拆成每个部门一个文件，只拆销售部和技术部」
- 「这批 PDF 按网格设置不同密码再分发」
- 「这个 Excel 要发给各网格，每个网格一个打开密码」
- 「先看看这张表有哪些字段可以拆」
- 「把这个文件夹里的表合成一张」/「把 12 个月的 sheet 合成一张」
- 「查一下收回来的表谁没交，应交的有城区、东城、西城」

## 和通用 Excel 读写技能的区别

| | 通用 Excel 技能 | ExcelRouter |
|---|---|---|
| 表头不在第一行（有大标题、多层合并表头） | 经常读错 | 自动识别 |
| 原表的字体 / 颜色 / 边框 / 列宽 | 基本丢失 | 完整保留，拆出来不用再修 |
| 一整个文件夹的表 | 一张一张来 | 一次拆完；同一个人散在多个表里会自动并成一份 |
| 拆完还要在每组里再按人拆 | 自己写循环 | 一条命令做完两级 |
| 一份 PDF / Word / Excel 发 100 个人、100 个不同密码 | 做不了 | AES-256；PDF 再加每人专属可溯源水印 |
| 几十个表合成一张，有人调过列顺序 | 按位置硬拼，列错位 | 按列名对齐；对不上的表单独点名，不硬合 |
| 收回来的表谁没交、谁漏填 | 一个个打开看 | 几秒出通报：未交 / 空表 / 哪列漏了第几行 |

## 它不做这些

写在前面，免得你装完才发现不合用：

- ❌ **不做表头扁平化 / 多层表头降维** —— 定位是「原样保留」表头，不是改造表头
- ❌ **不做数据透视、分类求和统计、清洗、图表** —— 汇总是把行合在一起，不做计算
- ❌ **不合不同模板的表** —— 能对上的列名不到一半的表不硬合，会单独点名请你核对
- ❌ **不替你发消息、不自动催办** —— 查收的通报写好了，由你自己复制发群
- ⚠️ **数据区的合并单元格不保留**（表头区的保留）—— 拆完每行各自取值，原来几行共用的格会空
- ⚠️ **`.xls` 旧格式**会先转成 xlsx，格式在这一步就丢了；在意格式请先另存为 `.xlsx`
- ⚠️ **源表公式若从未被 Excel 真正算过**（程序生成的表），读到的是空白；工具会提前警告你

## 数据不出本机

全程在你自己的机器上处理，**不联网、不上传任何数据到第三方**，断网也能用。
工资表、花名册、客户清单、成绩单这些东西，本来就不该传到别人的服务器上——
这是它和「在线拆分网站」的根本区别。

代码 MIT 开源可查；SkillHub 的两套安全扫描（keen / sanbu）结论均为**「安全，无风险」**。

## 装上之后

什么都不用装。第一次用时脚本会自动装好依赖（拆分、汇总、查收只要两个包，几秒钟，只装一次；
网络不通会换国内镜像再试）。不想自动装的环境设 `ER_NO_AUTO_INSTALL=1`，再手动：

```bash
pip install -r requirements.txt        # 拆分、汇总、查收只要这 2 个：openpyxl、xlrd
pip install -r requirements-pdf.txt    # 要做文件加密分发（PDF / Word / Excel）时再装
```

不用记命令，直接跟 AI 说人话：把表给它，它告诉你能按哪些字段拆、各拆成几组；
你挑一个，拆完自动打开结果文件夹。

**大表能拆吗？** 没有硬性上限，约 1.5 万单元格/秒：1 万行 × 15 列约 11 秒，
5 万行约 49 秒。跑的时候有进度心跳，不会让你对着静默的界面猜是不是卡死了。
