## 先说说我的场景

我在一家分公司做运营支持。每个月初，总部会发来当月的业绩明细——一个 Excel 文件，
5000 多行，按全公司所有人的数据列在一起。我要做的事：

1. 按**区域**拆成 4 份（华北、华东、华南、东北），发给 4 个区域经理
2. 每份里面再按**姓名**拆成每个人的独立文件，区域经理收到后转发给下面的人
3. 拆出来的表格**格式不能变**——表头是三行合并的复杂表头（公司大标题 + 业绩数据分组 + 列名），
   领导说过「发出去的东西不能乱七八糟的，格式要和原表一样」
4. 每个区域的所有文件**打成一个 ZIP**，微信发给对应的区域经理，省得一个个发

而且这不是偶尔干一次——**每个月都来一遍**。

以前我是手动筛选 + 复制粘贴 + 调格式 + 存文件。4 个区域 × 每个区域十几个人 = 几十个文件，
**每个月花半天时间在这件事上**。遇到季度汇总的时候更惨——要把 3 个月的表拼在一起再拆，
工作量翻倍。

## 后来我发现只需要 5 分钟

找到一个叫 **ExcelRouter** 的免费工具之后，整个流程变成了这样：

### 场景一：拆一个文件

最常见的情况——一个总表，按区域拆开，同时按人分。

1. 打开 ExcelRouter → 点「📄 选一个 Excel 文件」→ 选那个月度明细
2. 工具自动识别出表头的所有列名 → 在「拆分字段」下拉框里选「区域」
3. 勾上「✅ 同时拆到人」 → 在「按人拆分字段」选「姓名」
4. 点「▶ 开始拆分」

输出：
```
拆分结果/
├── 华北.xlsx          ← 华北区域的汇总表（格式完整）
├── 华北.zip           ← 里面有「汇总/」和「到人/张三.xlsx、李四.xlsx…」
├── 华东.xlsx
├── 华东.zip
├── 华南.xlsx
├── 华南.zip
├── 东北.xlsx
└── 东北.zip
```

**微信里直接把 ZIP 发给对应区域经理就行。** 对方解压后能看到汇总表和每个人的独立文件，
格式和原表一模一样。

### 场景二：一个文件夹拆一批表

季度汇总的时候，我有 3 个月的明细（1月.xlsx、2月.xlsx、3月.xlsx），想把同一个区域
3 个月的数据**合到一个文件里**再发。

1. 把 3 个文件放进一个文件夹
2. 打开 ExcelRouter → 点「📁 选整个文件夹（批量拆）」→ 选那个文件夹
3. 拆分字段选「区域」→ 高级设置里勾上「跨文件合并汇总」
4. 开始拆分

输出：每个区域一个文件，里面自动把 3 个月的数据按区域合在一起了。
**不用我手动复制粘贴 3 遍 × 4 个区域 = 12 遍的表格拼接。**

### 场景三：只拆其中几个区域

有时候不需要全拆——比如只有华北和华东的数据有更新。

高级设置里有个「只拆这些取值」，填上 `华北, 华东`，工具只输出这两个区域的结果。
**而且填过一次之后会自动记住，下个月打开工具就已经填好了**，不用每次重新设。

## 它凭什么能保住复杂表头

这是我最初搜方案时最头疼的问题。我的表头长这样（三行合并）：

```
|      北京A分公司 2026年1月 员工销售业绩明细表      |
|     基本信息      |         业绩数据         | 备注 |
| 工号 | 姓名 | 部门 | 销售额 | 完成率 | 奖金系数 | 备注 |
```

第一行是大标题跨所有列合并，第二行是分组标签，第三行才是真正的列名。

我试过的其他方案——Power Query 直接把合并单元格拆散变成空值，VBA 复制出来格式错位，
在线工具更别提了。

ExcelRouter 能保住的原因是它**用了 openpyxl 逐单元格复制格式**——字体、颜色、边框、
数字格式、列宽、合并区域全部原样搬过去。不是截图、不是另存 PDF，就是一个**格式完整的
.xlsx 文件**。打开后该拉公式拉公式，该改数改数，和手动从原表筛出来粘贴再调好格式的效果
一模一样——只是你不用手动做了。

## Q&A

**Q：我不会写代码，能用吗？**
能。整个操作就是选文件 → 选列名 → 点按钮，不需要写一行代码，也不需要装 Python。

**Q：表头不在第一行怎么办？**
工具默认会自动识别表头在第几行（扫描前 15 行）。如果识别不对，在「高级设置」里可以手动指定。

**Q：我每个月都拆同一种表，每次都要重新设置吗？**
不用。工具会**自动记住上次的设置**——拆分字段、输出路径、是否到人、
是否跨文件合并，下次打开都还在。

**Q：拆出来某列是空的？**
大概率是那列有公式但**从未被 Excel 计算过**（没有缓存值）。用 Excel/WPS 打开原文件
按一次 Ctrl+S 保存，再来拆就好了。工具也会提前检测并在日志里预警。

**Q：有 Mac 版吗？**
没有，只有 Windows。
