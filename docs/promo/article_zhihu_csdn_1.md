你一定遇到过这种事：

领导甩过来一个 Excel 总表——全公司 200 人的销售明细，十几列，好几千行。
然后说：「按部门拆开，每个部门一个文件，格式别变，下班前发给各部门经理。」

你心里一沉：**又来了**。

接下来一个多小时，你在做这件事：

1. 打开总表 → 按部门列筛选 → 选中"销售一部"的行
2. 复制 → 新建工作簿 → 粘贴 → 把表头也粘上 → 调格式
3. 存成「销售一部.xlsx」
4. 回到总表 → 取消筛选 → 重新筛选"销售二部"
5. 重复以上步骤……
6. 有 8 个部门，你重复了 8 遍

如果表头是那种**三行合并的复杂表头**（大标题跨列、分组标签、列名），粘贴完格式就乱了，
你还得手动一个个对着调。

如果领导又加一句：「顺便每个人也出一份」——那你今晚别想准时下班了。

## 我后来是怎么做的

我找到了一个免费的小工具叫 **ExcelRouter**，3 步搞定：

**第 1 步：选文件**
打开工具，点「选一个 Excel 文件」，选那个总表。

**第 2 步：选按哪列拆**
点一下「扫描字段」，工具自动识别出表头所有的列名。
我从下拉框里选了「所属部门」。

**第 3 步：点开始**
点「开始拆分」。

然后……就没了。输出文件夹里已经按部门分好了：销售一部.xlsx、销售二部.xlsx、市场部.xlsx……
**每个文件都有完整的表头，格式和原来一模一样**，包括那个三行合并的复杂表头。

**用了不到 1 分钟。**

如果领导说「每个人也出一份」，勾一下「同时拆到人」，选「姓名」列，再点一次。
每个部门文件夹里，又按姓名拆好了个人文件。自动打包成 ZIP，微信直接发给部门经理就行。

## 为什么不用 VBA / Power Query / 在线转换网站？

**说实话，我一开始也搜了不少方案。**

### ❌ 在线拆分网站

搜「Excel 拆分」排第一的就是各种在线工具。我试了两三个：

- 首先，**要把文件上传到别人的服务器**。我这是工资明细/结算数据，公司信息安全规定根本不允许。
- 其次，拆出来的文件**格式全没了**——合并表头变成了散列的单元格，字体颜色也没保住。
  领导说「格式别变」，这等于没做。
- 最后，大部分在线工具**只支持一次拆一个文件**，而且免费版有文件大小限制。

### ❌ VBA 宏

百度 / CSDN 上能搜到不少 VBA 代码，但：

- 我**不会写 VBA**，复制粘贴的代码跑不起来，报错看不懂。
- 即使有人写好了一版能跑的，换一个表（列名不同、表头行数不同）又得改代码。
- VBA **没法保留合并表头**的格式，复制粘贴出来表头就散了。

### ❌ Power Query

Excel 自带的 Power Query 理论上能做，但：

- 学习成本高——我要先学会 M 语言和数据模型的概念，只为了拆个表？
- 输出是**纯数据表**——原来的字体、颜色、边框、合并单元格全没了。
  Power Query 的定位就是「数据处理」，不是「保持原样分发」。
- 换一批表又得重新配一遍查询步骤。

### ✅ ExcelRouter

上面那些方案解决不了的两个核心问题，它都解决了：

1. **格式原样保留**——字体、颜色、边框、数字格式、三行合并表头全保住，拆出来的文件和原表
   长得一模一样，直接发给人不用再调。
2. **三步点击，不用写任何代码**——选文件 → 选按哪列拆 → 开始，普通办公人员就能用。

另外它还有几个让我挺惊喜的能力：

- **表头不在第一行也能自动找到**。我有些表前面有大标题、有空行，它能自动识别表头在第几行，
  不用我手动指定。
- **一次拆一整个文件夹**。我每个月都有一份表，12 个月 12 个文件，选整个文件夹，
  勾上「跨文件合并汇总」，它自动把同一个部门 12 个月的数据合到一个文件里。
- **数据不出本机**。全程离线处理，拔掉网线都能正常使用——工资明细、结算数据、客户信息
  这些敏感数据，不用担心上传到哪里去。

## 几个常见问题

**Q：支持 Mac 吗？**
不支持，只有 Windows 版（10/11）。

**Q：能拆多大的表？**
实测几万行没问题，有实时进度和心跳日志，不会假死。

**Q：.xls 老格式能用吗？**
能拆，数据完整，但旧格式转换后**格式保留不了**。格式重要就先另存为 .xlsx。

**Q：公司内部用、商用可以吗？**
MIT 协议，个人和商业都可以，无任何限制。
