## 正文

**ExcelRouter v3.0.0 · Excel 智能拆分汇总工具**

### 发下去的表，填错了也查得出

- **填写列可以写要求**：「让对方填写的列」里写 `走访日期（日期）`、`走访结果（已走访/未走访/拒访）`、
  `户数（整数）`、`联系电话（手机号）`、`备注（选填）`。
  - 下发时：对方在 Excel / WPS 里直接从下拉框选，填错格式当场被拦；
  - 查收时：多一个「**填写有误**」状态，通报只写哪一列、第几行，不把填错的内容贴进群里；
  - 汇总时：日期、数字、电话的各种写法自动统一（只改汇总表，交回的原文件不动）。
- **多轮查收说得出进展**：第二轮起通报写「比上次：新交 / 改好了 / 还差（漏填 5 格 → 1 格）」；
  每次查收另写一份「回收结果.json」，AI 技能能直接回答「东城还差什么」。
- 回收进度表的「漏填明细」改名「问题明细」，多一列「问题」。

### 拆分更稳、不误发

- **隐藏的内容默认不发出去**：隐藏的 sheet 不发，隐藏的列清空（仍隐藏）；隐藏的行照常发出并提醒。
  需要原样照发，在「高级设置」勾选「隐藏的 sheet 和列也照样发出」。
- **一行都不悄悄丢**：拆分字段空着的行，以前静默丢掉，现在放进「请核对_无归属.xlsx」；
  完成摘要多一行对账：「源表 N 行 = 拆出 + 合计等 + 没选的 + 没写分组」。各表自己的合计行不算无归属。
- **跨文件合并按列名对齐**：各表列顺序不同、多一列少一列都不会再错位；能对上的列名不到一半的，
  单独放进「{sheet}_2」，并提示这批表一共有几种模板。
- **拆分保留源表的下拉选项**（数据验证跟着行和列走）。
- 拆分列写着「NA」「N/A」「NULL」之类文字的行，以前会被当成空行丢掉，现在作为正常分组输出；
  快速模式下这类文字也不会再变成空白。（Excel 的错误值 `#N/A` 这类格子仍当作空，这样的行进「请核对_无归属」。）
- 以「=」开头的文字不会再变成公式（安全修复）。
- 修复：表头下面有日期列、表底有一行稀疏的「合计」时，整张表可能被误判跳过。

### 省事

- **📋 方案**：把一次的设置存成方案，下个月一键套用，也能发给同事；方案不存文件路径和截止时间。
  AI 技能用 `--recipe` 读同一份方案。
- **不再依赖 pandas**，保留格式和快速模式都更快（同一批文件实测快约 30%），安装包从约 55 MB 减到约 29 MB。

### AI 技能（excelrouter-skill）

- 首次运行只装 openpyxl、xlrd；`er_check` 输出逐人问题清单 `people`；四个脚本都支持 `--recipe` / `--save-recipe`；
  `er_split` 加 `--keep-hidden`。

数据仍然全程只在本机处理，不上传任何内容。
