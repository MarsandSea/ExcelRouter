它解决的是哪件事

如果你每个月都要干下面这类活，这个工具就是为它写的：

  • 全公司销售 / 结算明细，按部门或区域拆成多个文件，分别发给各负责人；
  • 工资条、考核表，一人一个独立文件，避免任何人看到别人的数据；
  • 门店 / 网格 / 项目台账，按编号拆分并自动打包成 ZIP 群发；
  • 学校成绩单，按班级拆分，班主任只拿到自己班的表；
  • 每月一份表、连着十几个月，把同一个部门的数据跨文件合并成一张汇总表；
  • 一份通报 PDF 要发给多个网格，每个网格一个专属密码 + 专属水印（泄露可溯源）。

核心差别在两个地方：一是格式——拆出来的文件，多层表头、合并单元格、 字体颜色、列宽跟原表一模一样，收件人拿到就能直接看，不用二次排版；二是批量—— 丢进去的可以是整个文件夹，几十张表一次拆完，同一个部门散落在多张表里的行还能自动并成一张。

三步就能拆完

1

选表格

选一个 Excel 文件，或者直接选整个文件夹批量拆。也可以把文件拖进窗口。

2

选字段

表头自动识别（哪怕不在第一行），下拉里选「按哪一列拆」，软件当场列出会拆成哪几组。

3

开始拆分

结果自动出现在数据旁边，按组打包好 ZIP。完成后给出摘要：拆了几组、几个文件、多少行。

常见问题

怎么把一个 Excel 按某一列拆分成多个文件？

选表格 → 在「拆分字段」下拉里选那一列 → 点开始。那列有几个不同的取值就生成几个文件， 文件名就是取值本身。不需要事先把取值列出来，软件会自己枚举并在开始前告诉你会拆成哪几组。

Excel 拆分后格式全丢了，怎么保留原来的表头和样式？

Power Query 和大多数脚本方案只搬数据，格式会被洗掉。ExcelRouter 默认的 「标准（保留格式）」模式会逐格复制字体、颜色、边框、数字格式、列宽以及合并的表头单元格， 拆出来的表和原表长得一样。文件很多、赶时间又不在乎排版时，可以切到 「极速（纯数据）」，速度会快很多。

两个已知限制：.xls 老格式转换后只保留数据；数据区的合并单元格暂不保留（表头的正常保留）。

工资条怎么一人一份批量拆出来？

勾上「同时拆到人」并指定姓名所在的字段。一次运行会同时产出两套结果：按部门/区域的 汇总，和每人一个独立文件。同一个人分散在多个月份表里的行会自动合并进他那一份。 还可以限定「只对文件名含『工资』的表拆到人」，一批表里混两种规则也能一次跑完。

处理工资、客户资料这类敏感数据，会不会被上传？

不会。它是本机运行的桌面程序，不联网、不上传、没有任何遥测或自动上报， 拔网线也能正常拆。源码以 MIT 协议公开在 GitHub 上，这一点可以自己翻代码核实。

银河麒麟 / 统信 UOS 上能用吗？

能。提供 x86_64 与 aarch64（飞腾 / 鲲鹏）两种免安装 tar.gz，目标机不需要装 Python。 解压后运行 ./启动ExcelRouter.sh。这是目前同类工具里少有的信创支持。

杀毒软件报毒，是不是有问题？

是误报，PyInstaller 打包的 Python 程序几乎都会遇到。优先下载 win64.zip（解压版）而不是单文件 exe，误报率明显更低。 详细说明见 FAQ · 杀毒软件误报。

它不做什么？

说清楚边界，免得下载了才发现不合用：不做表头扁平化 / 多层表头降维（定位是原样保留）； 不做把多个表合并成一个总表的通用合并（只在拆分时支持「同一取值跨文件合并」）； 不做数据透视、清洗与统计分析；没有 Mac 版，也没有在线版 （在线版意味着要上传数据，与「数据不出本机」冲突）。
