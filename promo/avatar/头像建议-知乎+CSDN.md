## 一、结论先说

| 你的问题 | 结论 |
|---|---|
| 头像里加链接？ | ❌ **不加**。头像不是可点区域，缩略图尺寸下链接会变成一排灰噪点，还容易被风控当成营销号特征 |
| 头像里加文字说明？ | ❌ **不加**。位置根本不够，硬塞就是糊成一坨 |
| 直接复用软件图标？ | ❌ **不要直接传 `app.png`**（实测有硬伤，见第三节）；✅ **复用品牌 + 重做一版「头像稿」** |
| 那链接和说明放哪？ | 放**昵称 + 个人简介**位（知乎「一句话介绍」/ CSDN「个人简介」）——那才是可点击、可复制的位置 |
| 推荐用哪版？ | **03 极简二拆**（主选）／ **05 汉字「拆」**（备选） |

一句话：**头像负责「被认出来」，昵称负责「被搜到」，简介负责「被点进去」。三件事不要挤在同一张图里。**

## 二、为什么头像不能塞链接或文字

1. **头像是个图形，不是入口。** 知乎/CSDN/微信全平台的头像都是不可点击的图片位——放上去的 URL 没人能点，用户只能手动抄，抄一个 30 字符的地址成功率极低。
2. **真实显示尺寸只有几十像素。** 信息流缩略图上头像通常就是 24–40px 量级（客户端版本 / 屏幕缩放会影响，别当硬指标），只有个人主页才会显示到 100px 左右。一行 30 字符的链接摊到 32px 宽度里，每个字符约 1×1 像素——等于没有。
3. **观感代价大于收益。** 头像带 URL / 二维码 / 小字水印，是典型的「营销号 / 微商」视觉特征，对知乎的推荐权重和读者信任度都是负分。你现在的定位是「40 岁自己动手做工具的开发者」，这个身份靠一张干净的品牌图 + 简介里的链接就能立住，不需要在头像里喊。

> 这一条其实和 SkillHub 上已经验证过的结论同源：**搜索结果里只读名字、几乎不读简介**。社交平台同理——头像和昵称进搜索结果，简介只在点进来之后才被看到。所以关键词放昵称，链接放简介。

## 三、直接复用 `app.png` 的两个实测问题

用脚本量过原图（256×256，透明底）：

| 实测项 | 结果 | 后果 |
|---|---|---|
| 图形实际占位 | x 16–239 / y 14–237，**四周各有 16px 透明边距** | 平台把方图裁成圆后，**上下左右各露出一条底色缺口** |
| 圆裁切边界采样 | 沿裁切圆周取 120 个点，**54 个点（45%）落在透明区** | 头像边缘出现四段豁口，白天看是白边、夜间模式看是黑边 |
| 自带投影 + 高光 | 渐变从 `#58B17F` 压到 `#166C40`，边缘有柔和投影 | 缩到 32px 时绿色发脏；即使把边距裁掉，外圈仍留一圈灰边 |

对照效果直接看图：`预览-尺寸阶梯.png` 的前两行（01 / 01b），以及 `预览-场景模拟.png` 底部左侧。

**注意：这不是说图标不好。** `app.png` 是一张合格的**应用图标**——圆角矩形、立体投影、内嵌细节，那是 exe / 快捷方式该有的样子。头像需要的是另一套设计语言：**全出血、无边框、大元素、抗缩小**。同一个品牌母题，两套呈现。

## 四、方案对比（01 / 01b 是对照组，不建议用）

| 编号 | 方案 | 128px | 64px | 32px | 适合谁 |
|---|---|---|---|---|---|
| 01 | 原图标直接传 | 勉强 | 糊 | 绿点 | ❌ 露底 + 糊，别用 |
| 01b | 原图标裁紧边距 | 勉强 | 糊 | 绿点 | ❌ 仍有灰边 + 糊 |
| **02** | **扁平三拆**（1→3） | 清楚 | 可辨 | 三粒点 | 想尽量贴近原图标形状 |
| **03** | **极简二拆**（1→2） | ⭐ 清楚 | ⭐ 可辨 | ⭐ 方块 + 两条杠 | ⭐ **主选**：品牌识别最强，和软件本体/GitHub/SkillHub 同族 |
| **04** | **字母 E + 三格** | ⭐ 清楚 | ⭐ 可辨 | ⭐ E 可辨 | 想要更「正经产品品牌」的调性 |
| **05** | **汉字「拆」** | ⭐ 清楚 | ⭐ 清楚 | ⭐ 可辨 | 想要「一眼看懂是干什么的」 |

**为什么主推 03：** 头像在信息流里 99% 的时间只有 32px，唯一任务是「让人认出这是同一个东西」。03 把原图标那个「一表拆多份」的母题**去壳、减元素、放大**，缩到 32px 还留有清晰形状，同时和你的 exe 图标、GitHub 仓库头像、SkillHub 卡片是同一套视觉——用户从知乎搜到、再跳到 Gitee 看到，能对上号。这是品牌资产的复利；02 保留了原图标的 7 个视觉单元，缩小时会糊成一坨绿。

**如果更看重「陌生人一眼知道你是干嘛的」**，用 05 汉字「拆」——中文单字标在 32px 下最清楚，配昵称「头看AI｜Excel批量拆分」语境完全够。代价是它比较像通用字标，跨平台和软件图标对不上号。

## 五、设计规范（以后改图照这个来）

| 项 | 规格 |
|---|---|
| 母版尺寸 | **1024×1024** PNG（另出 400×400 备用）；平台上传接受 1024 |
| 出血方式 | **全出血**——整张画布满铺品牌绿，**不画圆角矩形、不留透明边距、不做投影** |
| 为什么 | 平台无论裁圆、裁方、怎么压缩，都不会露底；夜间模式下也不会出现脏边 |
| 安全区 | 图形控制在画面内切圆的 **90%** 以内（约直径 920px）——裁圆裁不掉 |
| 品牌色 | 取自 `app.png` 实测渐变：**`#58B17F` → `#166C40`**（保证和软件图标同色系） |
| 元素预算 | **最多 5 个视觉单元**（块 + 线算一个）。原图标有 7 个，缩到 32px 必糊 |
| 验收动作 | 任何新稿先在 **32px** 下看一眼，看不清就重做。这是唯一的硬指标 |

## 六、链接和说明的正确落位（这才是你问的「加链接」）

**知乎**
- 昵称：`头看AI｜Excel批量拆分` ← **关键词必须进昵称**（搜索结果里只露昵称 + 头像，简介要点头进去才看得见）
- 一句话介绍：`AI 自动化实战 · 让 AI 干真实的活 ｜ 自己做工具 ｜ 免费开源 · 数据不出本机`
- 外链：放个人简介或**置顶回答的文末**（话术见 `推广总纲-20260916.md` §7：每篇换一句，别重复放同一句）

**CSDN**（对外链容忍度最高，可以直接给两个地址）
- 昵称：`头看AI`
- 个人简介：`AI 自动化实战 ｜ 免费开源工具 ExcelRouter：Excel 批量拆分 + PDF 加密分发 ｜ GitHub: github.com/MarsandSea/ExcelRouter ｜ 国内镜像: gitee.com/Marsandsea/Excelrouter`
- 博客公告位：建议把两个地址都写上（国内访问 GitHub 失败率高，**必须给 Gitee 镜像**）

**分工一句话**
```
头像  →  32px 下还认得出的图形     →  品牌识别
昵称  →  用户会打进搜索框的原话     →  被搜到
简介  →  链接 + 能/不能做什么       →  被点进去
```
