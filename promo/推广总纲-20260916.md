## 0. 一句话说清

| 项 | 内容 |
|---|---|
| 产品 | **ExcelRouter** —— Windows 开源（MIT）Excel 批量拆分 + PDF 加密分发工具 |
| 硬标签 | **免费 · 开源 · 数据不出本机**（全程本地跑，不上传） |
| 账号 | 小红书 **「头看AI」** |
| 定位 | **AI 自动化 —— 让 AI 干实际的活**（不是泛 AI，也不是纯 Excel 技巧） |
| 双卖点 | ① **一二级同时拆分**（差异化最强）② **桌面版 + AI Skill 同一套内核** |

**卖点怎么说**
- 一级 = 「拆分字段」按区域/部门拆；二级 = 勾「同时拆到人」按姓名拆到每个人。
- 一次运行同时产出「分组汇总 + 每人一份」两套结果；还能用「只处理文件名含 ___ 的表」
  在一批表里混用两种规则（如只对工资表拆到人）。
- 这是 Power Query 和绝大多数 VBA 方案做不到的 —— 所以它是**主推**。

## 2. 定位与内容配比

**为什么是「AI 自动化」而不是别的**

| 定位 | 竞争 | 结论 |
|---|---|---|
| 泛 AI（提示词 / AI 绘画 / AI 资讯） | 🔴 红海同质化 | 没优势，别碰 |
| 纯 Excel 办公技巧 | 🟡 池子太小、天花板低 | 只能当配菜 |
| **AI 干实际工作（办公自动化）** | 🟢 交叉蓝海 | ⭐ **就是这里** |

在这个赛道上，**有一件绝大多数 AI 博主拿不出的东西**：自己做了个能被 AI 真调用的工具。
别人讲 AI 自动化只能讲概念和提示词，你能演示"我说一句话，AI 真的把 300 人的表拆完了"。

**内容配比**
```
50%  AI 自动化（主线）
30%  用代码解决真实工作问题（差异化，别人抄不走）
20%  纯 Excel / 办公技巧（老本行，用 AI 视角重新包装）
```

**账号简介（建议改成）**
> AI 自动化实战 · 让 AI 干真实的活
> 表格 / 文档 / 批量处理 · 自己动手做工具

**语气原则（40 岁大叔风，硬朗）**
1. 开头**用场景，不用评价** —— 写"每周五下午我要拆 300 份表"，不写"这个工具太好用了"
2. **不称呼读者** —— 没有"姐妹们""宝子们"，中性内容本来就不用称呼
3. **把年龄写出来** —— "40 岁才开始折腾 AI"本身就是钩子
4. **先写知乎，再摘小红书** —— 用自己顺手的语气写，一次创作两个平台

## 3. 视频号（待定，但可能是主阵地）

用户实测：**视频号随手就过千观看，小红书只有几十**。但这两个数**不是一个单位**——
视频号自动播放划过就算，统计口径虚得多；小红书的"小眼睛"要真实曝光 + 停留才计。

**结论：数字不能直接比，但直觉可能是对的**，三条理由：
1. **内容形态对了** —— "一句话让 AI 拆表"本质是一个过程，录屏 30 秒比写 800 字直观十倍
2. **用户画像对了** —— 视频号中年用户占比高，正是"手下有一堆表、对 AI 好奇但不会用"的人
3. **不用装** —— 视频号里 40 岁大叔讲工具是常态，小红书让你别扭的那些东西这儿不需要

**建议（待用户点头）**：一鱼两吃
```
手机录屏 30-60 秒（说一句话 → AI 拆完 → 打开结果文件夹）
        ├── 视频号：直接发录屏          ← 主阵地
        └── 小红书：关键帧截图 3-4 张 + 短文  ← 吃搜索长尾
```
小红书不丢的理由：它是**唯一能沉淀搜索长尾的免费资产**（视频号内容三天就沉）。
一个要先说清的坑：视频号起量很依赖**社交推荐**（朋友点赞 → 推给朋友的朋友），
和"不想骚扰朋友"的顾虑有冲突，需要用户自己权衡。

## 6. 发布 SOP（每篇必做）

**发布流程最后一步固定为：发完别关 App → 立刻补自己第一条评论 → 长按置顶 → 截图。**

| 环节 | 要点 |
|---|---|
| 标题 | **搜索型**，把用户会打进搜索框的原话放进去（"工资条怎么一人一份发"），不写感受 |
| 正文 | 前 3 行自然埋关键词（Excel 拆分 / 工资条 / 按部门）；提一次产品名（小红书允许提名字，禁的是链接） |
| 配图 | **优先真实截图**（AI 对话、结果文件夹、报错窗口），少用设计卡片图 |
| 评论 | 一次别超 2 条，隔 10 分钟；**绝不出现微信/QQ/外链/二维码** |
| 破零评论 | **别找真实朋友**（非目标人群互动是脏数据）。用：文末埋有立场的问题 / 自己补增量评论 / 去同类博主评论区认真答问题 / 用篇数换概率 |
| 数据诊断 | 创作者中心 → 笔记诊断：显示「正常」= 内容赛马失败（改封面标题），显示「违规」才是真限流 |

| 内容类型 | 例子 | 引流方式 |
|---|---|---|
| **纯干货** | AI 代码踩坑 | **一个链接都不加** —— 它在攒信任，硬塞会掉赞 |

- **CSDN**：对外链容忍度最高、不折叠，可以直接给两个地址，但同样"方案讲完再提"。

## 8. GEO / AI 检索（让豆包们搜得到）

**核心认知**：豆包搜不到，不是优化问题，是**中文互联网上几乎没有提到 ExcelRouter 的第三方页面**——没东西可抓。
`llms.txt` 放在 GitHub 仓库里作用有限（AI 是去**搜索**，不会直接撞进仓库）。
真正的杠杆只有一个：**增加"能被搜索引擎收录、且提到 ExcelRouter"的公开页面数量**。

**做法（按有效性）**
1. **知乎回答** —— 国内 AI 检索首选来源就是知乎/公众号/CSDN/少数派。6 篇每篇提一次产品名。
2. **CSDN 同步发** —— 同一稿换标题双发，成本为零，抓取源翻倍。间隔 1-2 天，别同发（会被判重复）。
3. **Gitee 仓库完善** —— 国内 AI 更容易抓 Gitee：README 有完整中文描述、写明能/不能做什么、简介带关键词。
4. **（可选）写一篇对比型**：「Excel 批量拆分，我试了 5 种方案」—— AI 最爱抓列表型/对比型内容。

### CSDN「多平台发布」插件（09-22 查证）

CSDN 官方 Chrome/Edge 扩展。插件下载 `sync.csdn.net`，功能入口 `mp.csdn.net/multi-platform-sync`。
以 CSDN 为中枢，一键把文章同步到各平台的**草稿箱**：微信公众号 / 微博 / 知乎 / 掘金 /
百家号 / 博客园（部分版本还含今日头条、小红书长文）。

| 判断 | 说明 |
|---|---|
| ✅ **值得装** | 把"一稿多投"从 4 次复制粘贴压成 1 次点击。**GEO 要的就是页面数量**——多一个可收录页面 = 多一个 AI 抓取源 |
| ✅ 官方宣称带 GEO 强化 | 同步时带入 CSDN 的 TDK 结构化数据，对 AI 引用率有帮助 |
| ✅ 落到草稿不直发 | 同步过去先存草稿，不会误发；有同步历史可查 |
| ⚠️ **它是铺量工具，不是流量工具** | 别指望它带人来看。人不对的平台（掘金、博客园）当**纯抓取源**即可 |

**推荐用法（只做加法，不为它写新内容）**

```
CSDN 发完（勾原创）
   ↓ 插件勾选
掘金 + 博客园 + 百家号（知乎文章可选）
   ↓ 各平台草稿箱逐项检查
改标题 → 补封面 → 确认链接/产品名还在 → 发布
```

**四个坑**

1. **判重**：同一篇原文铺多平台，百度会去重、平台会互判搬运。→ 各平台**标题和开头各改一句**，发布隔开几天
2. **链接会被处理**：正文里的 GitHub / Gitee 地址同步到知乎、百家号可能被折叠甚至丢掉。→ **必须去草稿里点开看**，丢了就手动补"搜 ExcelRouter"
3. **封面 / 摘要不会自动带全**：CSDN 图床的封面到别的平台可能失效；公众号摘要要自己写
4. **小红书和公众号别用它发**：插件里那个"AI 图文同步"会**自动生成图片和文章**，跟我们
   "不编造 + 真实截图 + 硬朗风"的原则冲突；公众号没粉丝不值当。**小红书继续手发**

> **安全**：只从 `sync.csdn.net` 装官方版。这类插件要读各平台登录态（Cookie），
> 第三方打包的"同步神器"别装来路不明的（备选可看开源的 Wechatsync，29 平台、本地运行）。

**现实预期**
| 时间 | 能做到 |
|---|---|
| 1 个月 | 百度开始能搜到（知乎/CSDN 收录后） |
| 2-3 个月 | 问 AI"Excel 拆分工具有哪些"可能提到 |
| 半年+ | 问"ExcelRouter 是什么"能答出来 |

**做之前先验证**：去百度搜"ExcelRouter"。搜不到 → AI 更搜不到。第一阶段目标是**让百度能搜到**。
**不为豆包单开战线**（不单独发内容、不去"提交收录"）；真正的最高价值是 **Skill 被 AI 直接调用**（已实现）。
